# Logistics & Supply Chain Analytics — Power BI

## Project Overview
An end-to-end Power BI portfolio project analyzing logistics, delivery performance,
carriers, warehouses, product demand, inventory levels, shipping costs, and stockouts.

## Raw Data
The raw CSV files intentionally contain realistic data-quality problems:
- Missing values
- Duplicate order records
- Inconsistent category labels
- Invalid delivery days
- Missing shipping costs
- Negative inventory demand
- Zero-stock products

## Tables
- Orders_Raw.csv
- Products_Raw.csv
- Carriers_Raw.csv
- Warehouses_Raw.csv
- Inventory_Raw.csv

## Key KPIs
- Total Orders
- Total Shipping Cost
- Average Delivery Time
- On-Time Delivery Rate
- Delayed Orders
- Stockout Rate
- Total Quantity Shipped
- Inventory Units

- Power BI Desktop
- Power Query
