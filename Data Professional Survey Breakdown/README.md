# Data Professional Survey Breakdown — Power BI

## Project
`Data_Professional_Survey_PowerBI`

This project recreates the structure and analytical style of the supplied
**Data Professional Survey Breakdown** dashboard.

## Main KPIs
- Count of Survey Takers
- Average Age
- Average Salary
- Happiness With Work/Life Balance
- Happiness With Salary

## Main Visuals
- Country of Survey Takers — Treemap
- Average Salary By Job Title — Bar Chart
- Favorite Programming Language — Stacked Column Chart
- Difficulty to Break Into Data — Donut Chart
- Happiness With Work/Life Balance — Gauge
- Happiness With Salary — Gauge

## Dataset
- Raw rows: 642 (630 unique survey takers + intentional duplicates)
- Clean unique survey takers: 630
- The raw file intentionally includes:
  - Missing values
  - Duplicate rows
  - Inconsistent country labels
  - Inconsistent job-title labels
  - Invalid age values
  - Missing salary values
  - Text fields with extra spaces

## Tools
- Power BI Desktop
- Power Query
- DAX
